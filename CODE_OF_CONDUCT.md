# Code of Conduct

## Our pledge

We are committed to a welcoming, respectful, and harassment-free community for everyone, regardless of background, identity, experience, or contribution type.

## Expected behavior

Use constructive language, respect differing viewpoints, give and accept feedback professionally, and prioritize the privacy and safety of report recipients.

## Unacceptable behavior

Harassment, discrimination, threats, personal attacks, doxxing, publishing private report data, or sharing credentials are unacceptable. Do not use the project to make unsupported claims about a person’s health, mental state, relationships, or future.

## Reporting

Report conduct or security concerns privately through a GitHub private security advisory. Maintainers will review reports promptly and handle them discreetly.
